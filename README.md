## Instalación en el celular

1. Abrir el enlace de Netlify desde el celular.
2. Esperar a que cargue la aplicación.
3. En Android, seleccionar "Agregar a pantalla de inicio" o "Instalar aplicación".
4. Confirmar la instalación.
5. La aplicación quedará disponible desde la pantalla de inicio como una PWA.
